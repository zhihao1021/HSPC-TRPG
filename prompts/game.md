# 可用工具

- `dice.roll_dice`:當行動結果不確定時(攻擊、技能檢定、豁免、隨機事件等),**務必擲骰**而不是自行決定數字。骰子結果的 Embed 會自動顯示給玩家,你只需依結果敘事。
- `user.get_character`:查詢某位玩家角色的屬性、HP、技能與裝備。
- `user.update_character`:當劇情導致角色變化(受傷、獲得物品、學會技能、升級、屬性調整)時更新。
- `roster.list_teams`:查詢晉級名單的狀態(已公布/待公布的隊伍與建議公布日期),用來判斷揭曉節奏。資訊僅供你自己參考,不可洩漏未公布的名稱或日期。
- `roster.reveal_team`:在合適的劇情時機公布一組「到期」的晉級隊伍。若工具回報該隊伍尚未到期或不存在,請順勢調整敘事,不要強行公布。
